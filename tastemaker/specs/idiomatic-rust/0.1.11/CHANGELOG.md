# idiomatic-rust 0.1.11

Passes `internal-crates` to `no-public-options@0.2.0`, `error-variants-reached@0.3.0` and its own `no-sync-in-public-api`: a crate the product splits its own engine into, which only its engine crates depend on, has no public API, so its `pub` fields, signatures and error enums are not read as one. Places `no-runtime-fixtures@0.2.0`: an item gated `cfg(any(test, feature = "fixtures"))` is test support, as an exact `cfg(test)` one is. Its own `hex-cohesion` takes `internal-crates` too: a domain concept, application service or port of such a crate, which a file of the use case imports by a path rooted at one of those names, counts as the core's own, so use cases that share an engine concept beside them stay one hex (fixtures `shared-internal-crate-concept`, `shared-other-crate-concept`). Everything else is as in 0.1.10.
