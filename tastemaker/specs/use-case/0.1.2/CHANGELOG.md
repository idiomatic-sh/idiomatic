# use-case 0.1.2

The directory form of `use_case_test.rs`: `use_case_test/<scenario>.rs`, one file for each scenario, which `use_case_test.rs` declares. It is placed only with two or more files (`directory-form`) and splits along scenario, never by size: a long file is a prompt to look for the pattern it splits along. The rules that read the tests read the directory form too.
