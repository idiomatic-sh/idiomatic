# part-module 0.1.0

The module file of a nested part of a concept or an application operation, `<part>.rs` beside the part's directory. It replaces the borrowed `test-group-module` (a group of cases' template, whose content and help named tests) on the nested-part placements of concept 0.1.2 and application-service 0.1.2: one key, one meaning. The file declares the part's role files only; the placing spec holds that with `test-group-namespace` (`case-table = "refused"`).
