# constants

## 0.1.0

The first version: the file of a part's text constants, open so it asks only that the file exist. The `concept` spec places it with `count = { min = 0 }`.

## Renamed `constants`

The template and its file are `constants` and `constants.rs`, no longer `names` and `names.rs`. The plain word says what the file holds. The description stays: the constants the part's code uses; no literal sits in code. The v1 products place no such file.
