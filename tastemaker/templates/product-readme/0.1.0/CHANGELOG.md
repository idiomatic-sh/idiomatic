## 0.1.0

`## Install` with one `sh` block, between the purpose and `## Usage`. No `### Uninstall`
and no `## Crates`.

The first release. The template is `closed`: its content is the whole
document, compared in order:

- `# <product>`.
- One paragraph on one line: what the product is for.
- `## Usage` holding one `console` code block. `end-to-end` 0.2.0 runs it from the CLI
 crate's end-to-end test with `trycmd`, so the commands and their output cannot drift.

Nothing else: any other heading, paragraph, list or block is a finding.
