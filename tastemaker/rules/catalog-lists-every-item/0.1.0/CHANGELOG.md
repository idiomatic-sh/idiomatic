# catalog-lists-every-item 0.1.0

Every item module a collection file declares, other than the modules `except` lists, is an identifier of its catalog file. It replaces the relations service test `the_catalog_lists_exactly_the_folders_of_its_items`, which compared `read_dir` of `collections/relations/` with the catalog. Fixtures `every-item-is-listed` (pass) and `an-item-the-catalog-omits` (violation).
