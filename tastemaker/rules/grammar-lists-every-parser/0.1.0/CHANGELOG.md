# grammar-lists-every-parser 0.1.0

Every parser function of a grammar's adapter, a function of `parsers` with a parameter written as one of `input`, has a row of the grammar table in `grammar` whose `field` names it, as a string or as a constant holding one, and every row names such a function. It replaces the `ParsersListed` case of the RyoQL winnow adapter's test, which read `adapter.rs` as text with `include_str!`. Fixtures `every-parser-has-its-row` (pass, with a row named through a constant of another module), `a-parser-without-a-row` and `a-row-without-a-parser` (violations).
