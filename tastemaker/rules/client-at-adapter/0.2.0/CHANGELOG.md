# client-at-adapter 0.2.0

Where a client library may be named is read by the rule, not by its entry's excludes: a file the adapter spec places (as in 0.1.0), any file beneath an outbound port's `adapters/` (`**/outbound/*/adapters/**`, placed by any spec), a port's `**/outbound/*/factory.rs` and an edge's `**/composition.rs`. 0.1.0 counted only the adapter spec's own roles and left factory.rs and composition.rs to the entry's `exclude`, so a language crate, whose adapters its own spec places, excluded `**/adapters/**` in its manifest, a carve-out. An entry reads `**` and excludes no production role. Scenario `unplaced-adapter-tree-names-client-library`: the language adapter, the factory and the composition pass; the domain and `src/fixtures/x.rs` are reported. Everything else is as in 0.1.0, which stays as published: tastemaker and asymptote lock it.

Edited in place: the `[given]` reads `**` with no exclude, and the `domain-test` and `adapter-test` scenarios carry none, so the adapter test passes by the query and the domain test is reported by it; the description names factory.rs and composition.rs once.

Edited in place: an edge's composition is a `composition.rs` the specs place as one, read from the placement records as the adapter roles are: a `composition.rs` some template entry places (a command's or an SDK entry's `composition`, a language contract's `reader-composition`, a benchmark host's); scenarios `edge-s-composition-opens-client` and `unplaced-composition-names-client-library`, not a `composition.rs` in any directory: a domain `composition.rs` that names a client is reported. An entry keeps tests and fixtures out by its explicit test-role excludes, as idiomatic-rust places the rule: tests set a scene up with any library (PM ruling, 2026-11-11).

Edited in place: an edge's composition is read from the placement records by the template that placed it, `composition`, a `*-composition` (`command-composition`, a language contract's `reader-composition`) or a benchmark host's `workflow`, not by its path: a `composition.rs` a template entry places as another role is no edge's composition, and its client library is reported (scenario `composition-placed-by-another-template-names-client-library`).
