# no-serde-in-domain 0.1.0

The first release.

A `derive` naming `Serialize` or `Deserialize`, written in the domain or in a port's `types.rs`
or `interface.rs`, is a finding. An adapter's own schemas are outside the placement.

A command line's own `output/schemas.rs`, which writes the shapes of its machine-readable answers, is an edge that encodes.
