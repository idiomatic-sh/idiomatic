# no-tracker-text-shipped 0.1.0

No shipped text names the work that made it. A comment, prose line, string literal or data string
matching one of the entry's `patterns` (an issue id, a dated attribution) is reported.

Edited in place: the patterns also name the phrases that point at the process and not the product (`the owner`, `owner's decision`, `the spike`, `the devcontainer`, `an agent`), each with a failing scenario.
