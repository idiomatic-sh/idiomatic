# case-expectation

## 0.1.0

The first release. A finding is the identifier `is_ok` or `is_err`, or a tuple-struct pattern `Ok(_)` or `Err(_)`, in a file the entry selects.

A row's error is a full value, `Expect::Error(FooError::Bar)`, compared by equality: there is no selector row. Edited in place: the package is frozen.
