# pub-item-unreferenced-elsewhere 0.2.0

Two kinds of field are not read. A field of a type in a `schemas.rs` is the wire shape serde reads and writes by name, kept public so the schema is plain data; and a field of a type in a `fixtures.rs` or under `fixtures/` is a fake's, kept public for the tests that build it (`clippy::partial_pub_fields` asks one visibility of every field of a struct). 0.1.0 reported both, and the only way past was an ignore per field. Any other item of a fixtures file, a function or a type no other file names, is still reported. Scenarios `unreferenced-service-function` and `fixture-function-named-by-no-other-file` (reported), `schema-field-named-by-no-other-file` and `fixture-field-named-by-no-other-file` (not reported). Everything else is as in 0.1.0.
