# test-shape

## 0.1.0

The first release. A finding is a function whose attribute path ends in `test` and whose name is not `succeeds`, `refuses`, `fails` or `rejects`, in a file the entry selects.

A runner's body is read: it calls `run` with its own case word.

The runners are named for the case words and no longer required all four: which of them a file holds is `test-runners-match-rows`.
