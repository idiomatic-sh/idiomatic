# provider-imports

## 0.2.0

The scenarios' language placements are the one language 0.4.13 writes. The own `tastemaker.toml` places `source-import-allowlist@0.2.0` over itself and `src/tastemaker.toml`, with no params. It no longer places `src/tastemaker.toml` with `provider-allowances`: that template is deleted, and the language spec places the file with `language-source-allowances`. Everything else is as in 0.1.0. 0.1.0 is removed with this version: nothing has been released.
