- F1: RawKeyOrder is visibly the 13th contract, not PartitionOrder. All five consumers and order/firsts operations resolved in R.
- F2: Owned recycle/take-out is mandatory for Equality scratch and current Closure; C identifies bootstrap, mem::take, transfer and consumer lease sites.
- F3: Opaque payload migration must expose explicit shared-position/mark handles or equivalent whole-payload aliases, including weak identity and capacity. B identifies actual aliases.
- F4: Backend index Arc + common retained storage are intentional owner aliases today. Graph reclaim subtracts known owner aliases; one new payload Arc in both caches would require changing that rule, not a count assertion waiver.
- F5: Native-ready and invocation pre-gate are actual routes. Registered unsupported NativeLookup maps to WrongOperation; no current unsupported production call was found because both callers pre-gate. This is an API/lazy fallback contract gap; N/A standalone native-index retention is resolved.
- F6: Generic Arc plan key and Distinct predicate context pointer prevent broad canonical reuse; graph keys separately compare live exact selected positions and bind domain/direction. Selector address maps are immutable request metadata, not row identity. Actual canonical multi-consumer proof covers Equality/graph scopes, not every kind.
- F7: Fanout has actual independent retained storage and admission outside common ledger; not a second algorithm in the semantic posting kernel. No OR posting consumer exists in frozen source.
- F8: Predicate program and mutable DFS symbols are finite engine data/callback seams; new portable faults must preserve original first callback error, MissingInput mapping, NoSuchColumn, DuplicateOrder AND DuplicateDfsOrder, ShapeMismatch/NotRun/WrongOperation.
