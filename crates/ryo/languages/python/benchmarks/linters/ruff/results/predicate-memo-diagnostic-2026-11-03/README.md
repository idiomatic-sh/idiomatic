# Predicate memo diagnostic counts

These are **diagnostic-only** observations on the frozen 310-rule Django corpus (2,875 files), using feature-gated source patches and sealed workers. They are not speed comparisons. The [whole-corpus summary](full-summary.json) matched the frozen report and coverage (2,327 findings; 891,250 selected, 890,943 evaluated, 307 skipped, zero unknown), with zero counter overflow. It recorded 2,593,980 memo initializations, 2,570,073,913 initialized cells, 1,889,128 distinct touched cells, and 1,001,509,514 text-equality bypasses.

The separate [options.py reset-cost probe](options-reset-summary.json) kept exact output, zero overflow, and measured 0.329 ms total in the existing clear/resize operations across 1,851 resets and 6,600,670 initialized cells. This rejects memo reset as an explanation for a large options.py cost; it does not measure whole-corpus reset time or the cost of text-equality calls. [Source manifests](full-source-manifest.json) and [patches](full-instrumentation.patch.gz), plus the [worker seal](full-worker-seal.json), bind the whole-corpus counter route. The options probe has its own [manifest](options-source-manifest.json), [patch](options-reset-instrumentation.patch.gz), and [worker seal](options-worker-seal.json). The 190.8 MB raw full events remain outside Git; both summaries record their report and coverage seals.
