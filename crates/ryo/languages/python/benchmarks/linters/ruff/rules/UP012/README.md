UP012 recognizes redundant UTF-8 encoding on string literals and redundant explicit UTF-8 arguments on formatted strings. It uses decoded values, byte-exact call spans, and the standard suppression module. Keyword/positional argument shape, bytes receivers, dynamic encoding expressions, and non-ASCII default calls are covered by the cases.

A string literal with a part (not raw) that spells a `\u`, `\U` or `\N{...}` escape, or an octal escape above `\377`, is not reported, as Ruff 0.16.5 does not report it: none of those escapes can be written in a bytes literal. `\x` and octal escapes up to `\377` are judged by their decoded value. The cases' expectations are the pinned Ruff's findings; no case records a difference from it.
