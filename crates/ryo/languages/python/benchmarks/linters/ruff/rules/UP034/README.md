## Required generic token links (source draft)

Optional `token-link` uses existing physical native token IDs, with typed `next-token`, `matching-delimiter` (opening to closing), and `enclosing-delimiter` (token to immediate surrounding opening) edges. Missing links have no row, never sentinel IDs. Opening tokens refer to the stack before pushing; matching closing tokens refer to the outer stack after popping, excluding their own pair. Ordinary tokens refer to the current opener. Strings/comments remain opaque tokens; no raw-text delimiter scan or embedded-annotation duplication occurs.

Mismatched closing/error tokens establish no guessed enclosure and invalidate pairing knowledge; unmatched opening delimiters retain known-prefix edges but mark coverage partial at EOF. Existing lexical coverage still governs incomplete/truncated/invalid-byte input. The single stack pass takes O(native elements) time and O(delimiter depth) scratch, emits at most three links per token, and adds no model/cache/lifecycle owner. Lint trivia, commas/yield, cursor consumption and diagnostic policy remain in RyoQL. Draft tests are source-only until the integrated gate and actual candidate replay.
