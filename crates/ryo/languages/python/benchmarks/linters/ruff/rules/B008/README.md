Implements Ruff 0.16.5 `function_call_in_argument_default` and its immutable-annotation, mutable-constructor, immutable-constructor, and immutable-NewType helpers. Both positional and keyword-only defaults participate. Each lambda's own defaults are checked independently; traversing an outer default stops at a lambda.

The constructor catalogs deliberately preserve Ruff's distinctions: mutable constructors do not unwrap a subscript, immutable constructors unwrap one, and explicit `builtins` imports differ from implicit builtin origins for non-generic annotations and immutable constructor calls. Exempt calls still have their arguments visited. NewType exemptions require the resolved bare-name binding to be an unshadowed ordinary assignment with exactly two factory arguments and an immutable original type.

Annotation origins follow the checker analysis point. Eager cached bindings remain authoritative; postponed and otherwise unvisited names look up the completed current namespace after parameter binding. The reusable `immutable-annotations` helper partitions decisions by the actual caller node, including NewType checks whose factory expression belongs to a different lexical scope. The finite attribute transitions enumerate only prefixes of the upstream immutable catalog; they do not infer arbitrary expression identities or assign names across scopes. These transitions have two levels because every catalog path has at most three components.

`policy-full-cases.toml` retains full 310-rule reference arrays, including both exact tagged B006/B008 upstream fixtures; `cases.toml` projects the B008 acceptance profile. `cross-profile-cases.toml` preserves the final combined-run reproductions. This is bounded differential evidence, not a full 413-rule parity claim.

Source pin: `astral-sh/ruff` tag `0.16.5`, Python target `py310`. New source controls use actual pinned reference output; final cross-rule inputs reuse sealed reference records without rerunning Ruff.
