# idiomatic-sh-ryo  library ryo_cli
#
# The drafted public interface of edges/cli (folder today crates/ryo/cli; package idiomatic-sh-ryo; binary `ryo`), one
# public item per line, grouped and sorted within each group. Each line ends with two spaces and one tag: [main], [perf],
# [133], [changed: <what>] or [new]. The quotes behind the tags are in sheet.md sections 2 to 5, each with @REV:PATH:LINE.
# Paths are written with their real modules, NOT flat: the module paths are fixed by the shared Tastemaker spec
# `idiomatic.arch/cli` (0.13.0 on main, 0.12.3 on the tip) and the `command` spec, whose templates every product's command
# line follows (the command-line and command-tree contract tests name `ryo_cli::resources::command()`), so the path is
# part of the contract (sheet decision 3). check-types.py counts only flat names; the 25 type names defined here were
# checked by grep against every other api.txt on 28 Nov: none is defined elsewhere.
# The draft follows main's cli spec 0.13.0: the owner removed the `commands` bench there ("owner, option 1", spec
# CHANGELOG); the tip still carries it under 0.12.3. Sheet section 8.
# Owns: one `ryo` command line turned into one call of an inbound use case, its answer printed in the chosen format.
# No other crate may import ryo_cli (Tastemaker rule import-directions forbids `ryo_cli::*`); its public items exist for
# its own binary and its own integration tests.
# No layout word appears in any signature. No line names a ryo_table type.
# STATUS: drafted 28 Nov. Not reviewed, not agreed.
# COUNT: 58 public items (2 traits, 31 functions, 25 structs and enums) and 24 public modules, as on the tip less
# `linked_connections` and `linked_sdk` and plus `linked`; main had 58 items and 24 modules, the tip 59 and 24 (sheet
# sections 2 and 3). Tags: 7 [changed] lines (edge_at, resources::run, Edge, query run's run, three Remedy impls), 1 [new]
# (`linked`), every other line [perf] (identical on main where main has it). Every composition.rs changes privately.
