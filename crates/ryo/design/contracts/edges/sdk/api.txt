# idiomatic-sh-ryo-sdk  library ryo
#
# The drafted public interface of edges/sdk, one public item per line, grouped by resource and sorted within each group.
# Each line ends with two spaces and one tag: [main], [perf], [133], [changed: <what>] or [new].
# The quotes behind every tag are in sheet.md, sections 2 to 5, each with @<rev>:<path>:<line>.
# A re-export is written `pub use ryo::<resource>::<Name> = <defining crate>::<Name>`: the SDK defines nothing it re-exports;
# the fields and variants of a re-exported type are on its owner's listing and are not repeated here.
# Owns: what a user of Ryo calls, and the composition behind it ("the edge owned by the sdk composes", owner 2 Oct). It builds
# every port and use case once in `Linter::new` (or per call for the four catalog and query calls) and hands them down.
# It does NOT lint, validate, describe, parse, keep, list files or schedule: each is the crate it composes.
# No layout word in any signature. Lines marked UNPROVEN name a type of ryo_table and stand only once
# domain/table/spike.md records a pass.
# STATUS: drafted 28 Nov. Not reviewed, not agreed.
# COUNT: 133 public items: 10 defined here (Linter, Cache, WorkerPool, Workers, RunRequest, RunReport, Heading, Row, RunError,
# DEFAULT_LIMIT) with 5 functions on them (Linter::new, Linter::lint, Debug, two From), 7 free functions (query 3, operator 2,
# relation 2) and 111 re-exports (inbound/lint 46, inbound/describe 28, inbound/validate 3, the domain and outbound concepts
# 34); plus 7 RunError variants and 2 Cache variants. 7 items are UNPROVEN (they name ryo_table). Of the 133, 22 are the
# SDK's own (defined or free functions). Main: 675 named items (155 outside `languages`), tip: 739 (147 outside
