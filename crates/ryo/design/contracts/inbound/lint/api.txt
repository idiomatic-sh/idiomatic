# idiomatic-sh-ryo-lint  library ryo_lint
#
# The drafted public interface of inbound/lint, one public item per line, grouped and sorted within each group.
# Each line ends with two spaces and one tag: [main], [perf], [133], [changed: <what>] or [new].
# The quotes behind every tag are in sheet.md sections 2 to 5, each with @<rev>:<path>:<line>.
# Paths are written flat (ryo_lint::Item), as the table, symbols, execute and programs listings write theirs; the built
# crate keeps its nu-hex modules (inbound/use_cases/lint, outbound/memory, domain/{requests, reports, admission, decoding}).
# Owns: one lint call: a list of rule requests in, one report (or one refusal) per request out, in request order.
# It does NOT parse, lower, bind or freeze rules (domain/programs, which it calls once per call), decide which programs
# can answer a file (application/screen, which it prepares once per language per call), run a file (application/execute,
# which it calls once per file), run the cross-file phase (application/project), list or read files and match path
# globs (outbound/corpus), keep anything between processes (outbound/cache), start workers (outbound/scheduler) or
# build any of those (the edges compose: "the edge owned by the sdk composes").
# No layout word appears in any signature: no table, column store, row slot, `Batch`, `World`, `Run` or `Live`.
# Lines marked UNPROVEN name a type of ryo_table and stand only once domain/table/spike.md records a pass.
# STATUS: drafted 28 Nov. Not reviewed, not agreed.
# COUNT: 121 listing lines = 62 public items (2 traits, 4 trait methods, 1 factory fn, 1 constructor, 1 bench-hooks fn,
# 51 structs and enums, 2 impl lines) plus 59 enum variants; tags: 76 [perf], 34 [changed], 9 [main], 2 [new], 0 [133].
# Main had 41 public items for the concept in core beside the SDK lint module's 37 (sheet section 2), the tip 34 in core
# beside the SDK lint module's 40 (section 3). At the tip the SDK's `linter` module re-exports 31 items of its lint module
# and 36 lines of its own `domain` types; those that are not lint's move to the sheets of their concepts (decision 1).
