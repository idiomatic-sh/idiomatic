# idiomatic-sh-ryo-language  library ryo_language
#
# The drafted public interface of outbound/language, one public item per line, sorted within each group.
# Each line ends with two spaces and one tag: [main], [perf], [133], [changed: <what>] or [new].
# Quotes with @<rev>:<path>:<line> are in the sheet, sections 2 to 5; this listing carries only the tag.
# Types named from other sheets (never redefined here): ryo_table::{CellWord, Count, KindBits, TableFill, TreeRead,
# TreeWrite} (UNPROVEN until domain/table/spike.md passes); ryo_symbols::SymbolLayer (symbols decision 3; refused, the
# line reads today's FileWords); ryo_relations::{Relation, Column, RelationsItem, Rows, RowWriter, FileId, AbsenceCause,
# Missing, OptionalCapability, UnknownName, KindVocabularies}; ryo_operators::{Demand, RenderRequests, RenderOutcomes}
# (sheet decision 4); ryo_store::{FileTree, FileTreeWriter} (outbound/store; sheet decision 2, the store's decision 1).
# The per-file names are written where they are today: `Symbols` (the library's `symbols::Symbols`), `ByteSlice` here, `Symbol` in relations (the relations
# listing moves it to symbols, the symbols listing does not take it; sheet section 11); `NameText` is the table listing's.
# `KindVocabularies` is written as the plan listing writes it (ryo_relations); the relations listing does not define it.
# No layout word in any signature: NodeTable, NodeTableBuilder, FilledColumns, FactColumn are absent on purpose.
# Not agreed by the owner.
