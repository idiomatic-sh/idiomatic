# Owns: the cross-file phase of a request. What each file hands over is held, read by key, released after its last
# reader, and the cross-file rules run over it once, after the last file. The project's own relations are read here,
# once per request, and lent to each file's visit through execute's `ProjectTablesPort`.

# `ProjectUseCase` (the manifests a language reads). Whether the crate is renamed `cross_file` too is decision 1.

# `HashMap<usize, FileFrontier>` and `Vec<u64>` are absent on purpose (sheet section 9).

# the table sheet does not yet carry.
