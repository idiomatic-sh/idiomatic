# ---- how it is built ----
# Nothing. The crate has no implementation and no constructor: an edge builds the dictionary and hands it
# in; a caller is generic over `S: SymbolsUseCase`, never `dyn`, so no dictionary call is a virtual call
# in the hot path (sheet section 9, "Crossing frequency"). The freeze/worker pair is the one place a
# concrete type is named, and `FrozenSymbols` is this crate's own (sheet decision 5 — it may instead be an
# associated type of the port).
