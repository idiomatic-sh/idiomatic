# ---- how it is built ----
# Nothing. The crate has no implementation and no constructor: an edge builds the store
# (`outbound/store`), which implements `TablePort`, and hands it in. Callers are generic over
# `S: TablePort`, never `dyn`, so the store's type is fixed at compile time (sheet section 9,
# "Crossing frequency"; sheet decision 1).
