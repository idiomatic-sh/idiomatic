# The drafted public interface of domain/plan, one public item per line, grouped and sorted within each group.
# Each line ends with two spaces and one tag: [main], [perf], [133], [changed: <what>] or [new].
# A quoted-from-code line carries @<rev>:<path>:<line> in the sheet, section 5; this listing carries only the tag.

# Owns: the plan: a pack's checked programs lowered to one plan of shared steps, and what that plan decides before the
# first file (its marks, each rule's file/cross-file cut, the kind words it asks). It does NOT parse (ryoql), does NOT
# say what an operator means or reads (operators), does NOT bind or freeze a request's programs (programs).
# Types named from other sheets (never redefined here): ryo_operators::{OperatorCall, StepNumber, StepScope, ColumnSet,
# PlanConstant, LogicalProgram, CompareUseCase} (domain/operators/api.txt); ryo_ryoql::{CheckedQuery, RuleProgram,
# ParsedModules, ObservationName} (domain/ryoql/api.txt); ryo_table::{ColumnName, ColumnNumber} (domain/table/api.txt,
# UNPROVEN until domain/table/spike.md passes); ryo_relations::{HostedRelation, RelationName, NodeExtent, KindVocabularies,
# KindWord, LanguageName} (relations; all but NodeExtent are not yet on the relations listing: sheet section 11, decision 3).
# No layout word appears in any signature (no rows, columns as storage, cells, Vec<Vec<..>>).
