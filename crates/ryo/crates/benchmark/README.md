# idiomatic-sh-ryo-benchmark

Shared development harness for comparing Ryo with pinned linter defaults.

## Domains

### candidate_rules

Pure selection, dependency retention and declared rule configuration.

### canonical_text

The compact sorted-key document every pinned digest is taken over.

### diagnostics

Canonical finding multisets retain duplicate occurrences, exact paths and byte locations.

### discrepancy

A pinned reference may differ from the intended contract only with complete, known and evidenced identities.

### invocation_identity

Invocation spellings are normalized against the state boundary and request root, identically for captures and replay.

### measurements

Process observations separate measured wall time from decoded reports.

### process_failure

An explicit completed process failure binds its templates and its exact-binary archive group.

### registered_inputs

The declared inputs of a registered case, resolved the same way for registration and for its receipts.

### suite

Pinned profiles, authored cases and shared project inputs define the benchmark contract.
