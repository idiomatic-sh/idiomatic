# idiomatic-sh-ryo-benchmark-contracts

Shared typed benchmark boundary data without audit, certification, execution or publication authority.

## Domains

### artifacts

Exact artifact identity retains the original framing and display vocabulary.

### context

Declared and observed source context and owned rule-observation declarations preserve their existing data semantics.

### documents

The registered case and native observation documents are plain values that both the suite and the inventory ports read and write.

### measurements

Raw process measurements and borrowed publication observations carry no certified sample constructor.

### process

Declared process expectations and archived observations remain distinct from diagnostic reports.

### receipts

The audit of registered case receipts reports which cases verified and which failed, with their identities.

### reports

Canonical findings, explicit producer metadata, coverage and report comparisons remain independent evidence dimensions.

### requests

Benchmark and worker invocations carry explicit configuration and immutable source selections without acquiring engine state.

### workloads

Pinned projects, tools, cases and requests share one definition across benchmark layers and language compositions.
