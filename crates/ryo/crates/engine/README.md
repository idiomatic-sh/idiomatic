# idiomatic-sh-ryo-engine

Lowers each rule's plan into per-candidate programs in process and runs them on one file at a time over the walk and fact contracts, through the public inbound load, scan and project use cases; the host owns reading, storing and reporting.

## Domains

### code

A rule set's programs as the executor runs them and the pack stores them: sixteen-byte words in one arena, with the one constructor and the one reader of each code.

### counting

What a measuring worker counted, the counts of several workers added up, and the work ledger read off them.

### digests

The digest that names a plan's step by everything it reads, a bound value included: sixteen bytes of blake3, the same on every build, toolchain and machine.

### encoding

A lowered pack written as code, every site and index numbered, with no count cut to fit a width and a file-sized word only where it may stand.

### findings

The rows a scan hands over, the work notices beside them, the frontier rows the project pass reads back, and what a scan counted.

### lowered

A rule set as the lowering writes it: the pack's definitions and made tables once each, then each rule's own program, with the cost class of each fill.

### lowering

Turns the selected rules' plans into one lowered pack, and names each rule it refuses with the step that cannot be evaluated or the count that cannot be written.

### packs

The byte form of a rule set's programs, written for a pack digest and engine version and read back for the same.

### passes

The load-time passes over a lowered pack, in their one order.

### programs

The programs of a rule set, opaque outside the crate, and what the host reads of them.

### scratch

A worker's per-file state, cleared per file and never freed.

### statistics

What a sample run measured of a rule set's units, the bytes that carry it, and its decoded form.

### steps

The instruction set the lowering writes and the stages of a fill's pipeline, each with a cost class that is a property of the item alone.
