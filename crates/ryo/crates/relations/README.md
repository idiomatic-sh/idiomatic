# idiomatic-sh-ryo-relations

The portable relation catalog, its typed row and column schemas, closed term vocabulary, and typed absence causes. Language providers keep parsing, readers and file models. The common engine keeps acquisition, scheduling, storage, indexing, cache admission, invalidation and lifetime.

## Domains

### answers

The generic absence causes a language can report for a relation. Provider readers and sealed support answers remain in `ryo-language`.

### kinds

The hygienic numbering and naming macro for a provider's node and token kinds. Its generated types are relation contract types.

### relations

The exhaustive catalog of relations, typed columns and rows, optional capability declarations, and pure schema lookups.

### terms

Closed vocabularies and symbol identities used by relation cells and catalog metadata.
