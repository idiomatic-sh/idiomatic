# idiomatic-sh-ryo-operators

Owns portable primitive meaning through the public inbound operators use case. The execution engine owns source acquisition, matcher preparation, grouping, scratch, delivery, publication, cancellation, and lifetime. Domain implementation modules remain private.

## Domains

### aggregate

Formats engine-reduced group keys, optional digest, and saturated count without acquiring or retaining the contributing population.

### append

Combines borrowed row inputs in source order while preserving their column semantics.

### axis

Emits a row for each candidate an engine axis walk admits, in walk order, stopping at the first for the nearest ancestor.

### capture

Enumerates nonempty path-slot matches over UTF-8 character boundaries with explicit slash-crossing behavior.

### closure

Emits the partition key, the source and each vertex the engine's reachability walk reaches from every source of every partition.

### contract

Defines borrowed semantic requests, answers, and finite engine-provided drivers exposed through the inbound interface.

### cycles

Marks the nodes that lie on a cycle of engine-prepared adjacency, where a component of more than one node or a self edge is a cycle and a chain is not.

### equality_join

Combines admitted matching rows while preserving bag order, projections, and deferred physical positions.

### evaluation

Evaluates one plan operation of any kind over the engine's driver port: one arm per kind, each calling that kind's own meaning.

### fits_rendered

Measures the physical line width of a source prefix and an already rendered candidate, with tab stops and Unicode width.

### ordered_dfs

Emits each edge an ordered depth-first visit reaches from every distinct root, with the root's keys and the visit's ordinal.

### ordered_existence

Flags strict partition extrema over engine-admitted whole-number inputs and engine-owned scratch.

### ordered_match

Pairs ordered keys in FIFO order and projects each accepted pair before downstream delivery.

### project

Selects requested columns in authored order, preserving duplicates and the first missing-column error.

### rank

Finds the first matching resolved text-set layer without owning text-set resolution or storage.

### reduction

Reduces count and digest groups through borrowed engine-owned populations, prepared key order, and streaming scratch.

### render_batch

Refuses a batch holding an unsupported answer before any delivery, then delivers the known texts in order.

### replace

Applies literal replacement through a borrowed prepared regular expression and caller-owned text scratch.

### select

Applies predicate outcome before reading kept columns, preserving the original row for an empty projection.

### set_rows

Applies union, intersection, difference, and antijoin policies through borrowed membership and distinctness drivers.

### source_matches

Formats physical occurrence and capture spans with exact line tracking and immediate delivery failure.

### span_between

Composes checked half-open endpoints from two span cells against an engine-supplied source length.

### span_bounds

Extracts checked physical endpoints from a declared span column.

### table_rows

Delivers, for each binding table, the texts under the requested keys, refusing a table that lacks a key before its row.

### words

Splits resolved Unicode text into lowercase words using the original letter, digit, and case-boundary policy.
