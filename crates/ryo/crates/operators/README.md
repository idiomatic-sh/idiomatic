# idiomatic-sh-ryo-operators

Owns pure row algorithms behind an inbound capability contract; the core owns acquisition, scheduling, distinct work, resources, publication and cancellation, and its outbound adapter calls this capability over borrowed rows.

## Domains

### append

Combines borrowed row inputs in source order while preserving their column semantics.

### contract

Defines portable borrowed row and column values exchanged by operator semantics without core engine ownership.

### project

Selects the requested columns while preserving row order and reporting absent columns.
